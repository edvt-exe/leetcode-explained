# LeetCode Practice & DSA Solutions

Hi! This repository is where I keep track of my progress with Data Structures and Algorithms. 

I'm currently working my way through the Blind 75 list to prepare for technical interviews and improve my problem-solving skills. My main goal isn't just to grind as many problems as possible, but to actually understand the underlying patterns (like Two Pointers, Sliding Window, etc.) and write clean, readable code.

## How it's organized
* **Language:** C++
* **Workflow:** These solutions are pushed automatically from LeetCode using the LeetHub extension whenever I get an "Accepted" result. 

## Future plans
Right now, this repo just holds my raw code. In the near future, I plan to build a small personal website/blog where I'll take these solutions and explain my thought process, the approach I chose, and the time/space complexities for each problem.

Thanks for stopping by!
